# 让搜索找到真正需要的内容

搜索的起点是一个具体问题。先输入最容易记住的两个关键词，再根据结果缩小范围，比不断翻看文件夹更容易找到原文。

## 组合关键词

输入 `本地 搜索`，查看同时包含两个词的资料。搜索覆盖标题、正文、标签和相对路径，不必记住完整文件名。

## 保留完整短语

使用 `"阅读视图"` 查询连续出现的短语。需要排除无关内容时，可以使用 `搜索 -临时`。

## 缩小范围

在全部目录中寻找线索，再用格式和来源筛选结果。结果中的高亮帮助你判断上下文，正文命中导航帮助你在长文里继续查找。

## 回到原文

找到一段有用的内容后，先读前后的段落，再决定是否引用。阅读视图适合浏览，原网页适合检查保存时的上下文和排版。

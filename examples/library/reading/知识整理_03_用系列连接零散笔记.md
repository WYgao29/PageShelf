# 用系列连接零散笔记

一组笔记可以围绕一个问题持续生长。给文章加上稳定的系列名和编号，下一次阅读时就不用重新判断顺序。

## 使用简单的命名

`知识整理_01_开始.md` 和 `知识整理_02_搜索.md` 会归到同一个系列。系列导航会按编号排列文章。

## 用双链连接相关内容

在 Markdown 中写下 [[知识整理_01_把收藏变成随时可查的资料库|资料库的起点]]，就能在同一来源中跳转到相关笔记。

## 把结构留在文件里

系列名、编号和链接都可以用普通文件和文本表达。资料整理不必依赖另一个数据库，离开阅读器之后也能继续使用。

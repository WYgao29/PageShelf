# 把收藏变成随时可查的资料库

保存一篇文章很容易。真正有用的是：当一个问题再次出现时，你能找到它、读懂它，并把它接回自己的思考。

> 资料的价值，在于它下一次被找到的时候。

## 从一个文件夹开始

把网页存档、研究笔记和项目资料放在自己熟悉的文件夹里。PageShelf 直接读取这些文件，把目录、文章列表和正文放在同一个窗口中。

文件仍由你管理。你可以继续在编辑器里写 Markdown，也可以在访达中整理 HTML 和 MHTML 存档。整理好以后，重新扫描来源目录即可更新列表。

## 为不同资料保留合适的阅读方式

| 资料 | 适合的方式 |
| --- | --- |
| 保存的网页 | 阅读视图，专注正文 |
| 需要查看排版的存档 | 原网页，保留原来的布局 |
| 自己写的笔记 | Markdown，保留结构与双链 |

## 用问题找回内容

搜索不只匹配标题，也会检查正文、标签和相对路径。试着搜索 `本地 搜索`，找到同时讨论这两个概念的资料；也可以用双引号查询完整短语。

## 让系列自然形成

给同一主题的文章使用连续编号，例如 `知识整理_01_开始.md`、`知识整理_02_搜索.md`。PageShelf 会识别系列，让你按顺序阅读，也能随时跳到相关章节。

## 保留一条返回的路

每次整理只解决一个实际问题：这篇内容为什么值得保存？下次会用什么词寻找它？它与哪篇笔记有关？可以从 [[知识整理_02_让搜索找到真正需要的内容|让搜索找到真正需要的内容]] 继续阅读。

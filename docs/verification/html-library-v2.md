## 废纸篓与错误状态

[原生废纸篓记录](native-trash-2026-10-05.json)区分两条路径：系统 `/usr/bin/trash --` 成功移动专用文件，Finder「放回原处」恢复原路径，60 字节内容与 SHA-256 一致。

受控让 CLI 不可用后，Finder 回退在本机两次调用均被 15 秒超时终止，没有成功证据。固定 AppleScript 编译通过，测试文件内容未变；具体系统原因未确认，保留为待复测项。CLI→Finder 只处理剩余文件、207 部分成功和失败无源文件 `unlink` 均已通过命令注入行为测试。

空库、空目录、失效、无权限、损坏/高版本配置、扫描 issue、Trash 全部失败与部分成功由 API/文件系统夹具覆盖；无权限注入 `EACCES`，没有撤销用户真实目录权限。界面测试覆盖筛选空结果重置、服务断连重试、迟到预检、阅读/搜索过期响应、Trash 207/500 后显示幸存格式或失败信息。重试会重新发起对应请求。

占用端口测试使用临时监听和独立子进程，重复启动退出码 0、提示当前端口、stderr 无堆栈。生成的 plist 已验证 `KeepAlive.SuccessfulExit=false`；真实 plist 未更新，登录/重启与生产日志 60 秒观察待发布时执行。

# PageShelf 使用指南

[返回项目主页](../README.zh-CN.md)

PageShelf 是 macOS 本机资料阅读器，支持 HTML、MHTML 和 Markdown。资料保存在原文件夹，应用提供目录管理、全文搜索、阅读视图和系列导航。

## 安装与打开

从 [GitHub Releases](https://github.com/WYgao29/PageShelf/releases/latest) 下载 Apple Silicon Mac 版本，解压后将 **PageShelf.app** 拖到“应用程序”。自行构建的产物位于 `release/PageShelf-darwin-arm64/`。应用尚未签名和公证；如果系统阻止打开，请查看“系统设置 → 隐私与安全性”，确认来源后选择“仍要打开”。

首次使用点击“添加目录”，选择文件夹或粘贴路径；预检通过后再添加。支持 `.html`、`.htm`、`.mhtml`、`.mht`、`.md`，相同路径和主干的多种格式合并为一个条目。

## 目录与搜索

来源显示名支持 1–40 个字符；添加前检查路径、重复、文件/条目数和父子目录重叠。父子来源按最深可用目录归属，不重复计数；停用、失效或移除子目录后，父目录会重新收录。移除来源只取消索引，原文章保留。

目录管理支持改名、重新定位、停用/启用、系列识别、增量/全量重扫、访达显示和移除。重新定位保留来源 ID 与条目链接。拖动拖柄或聚焦后按 `Alt+↑/↓` 排序。扫描最多同时处理两个来源，扫描期间可以浏览已有结果、滚动和搜索；进度及问题列表在界面显示。

搜索覆盖标题、系列、标签、相对路径和正文。空格表示 AND，双引号表示短语，`-词` 排除内容。可选当前/全部目录、HTML（含 MHTML）/MHTML/Markdown、系列/单篇，以及相关度/更新时间/标题/系列顺序。结果显示高亮和正文命中数；分组默认六篇，可展开，每次继续加载 100 条。

## 阅读与界面

阅读区支持原网页、Markdown 和抽取正文；短 HTML 抽取不足 200 字时说明原因并显示原网页，短 Markdown 按笔记阅读。可通过正文目录跳转标题，系列上一篇/下一篇使用完整系列顺序。双链在同一来源中解析，外部图片显示占位，本地图片校验来源边界与真实类型。

亮色、暗色、跟随系统三态可切换；`Aa` 提供 15/17/19/21 px。分隔条可拖动、用方向键每次调整 16 px，双击恢复 252/384 px。目录、系列、查询、筛选、排序、文章和视图支持后退/前进并在重启后恢复。主题、字号和栏宽本机保存；没有已读、收藏或持久化阅读进度。

原网页处于独立 sandbox 中；脚本不能执行，也无法调用桌面接口。外链经应用内确认后才在默认浏览器打开，界面与正文不自动访问网络。原文件保存和路径复制在“文章操作”中；列表的 ⌘ 点击或菜单可在应用新窗口打开原网页。

| 快捷键 | 操作 |
|---|---|
| `⌘K` / `/` | 聚焦搜索 |
| `Esc` | 关闭菜单/弹窗，或清空搜索 |
| `j` / `k` / `Enter` | 下一条 / 上一条 / 打开 |
| `[` / `]` | 系列上一篇 / 下一篇 |
| `v` | 切换阅读视图 |
| `n` / `Shift+N` | 下一处 / 上一处正文命中 |
| `g a` / `g 1–9` | 全部目录 / 指定目录；一秒内连续输入 |
| `Shift+R` / `Shift+M` | 全部重扫 / 目录管理 |
| `t` / `⌘\` / `?` | 主题 / 侧栏 / 帮助 |
| `⌘[` / `⌘]` | 后退 / 前进 |

单字母快捷键在输入、可编辑区和弹窗中禁用；其他平台用 Ctrl 替代 ⌘。菜单“显示”和“前往”列出相应操作。窄窗通过来源按钮访问目录。

## 废纸篓与恢复

“文章操作 → 移入废纸篓…”先列出全部关联文件，默认聚焦“取消”。只有最终确认才使用系统 trash，必要时由访达移动；从不直接删除源文件。部分成功时保留幸存格式并允许重试，全部失败时显示错误。

恢复时在访达废纸篓选中文件，选择“放回原处”，然后重扫该来源。目录管理和成功提示均可打开废纸篓。

## 数据与缓存

资料库配置仍在 `~/.html-library/config.json`；`HTML_LIBRARY_DATA_DIR` 可为开发和测试指定隔离目录。索引在内存中，启动时重建。

v1 配置先在内存中迁移，首次写入前保存原字节到 `config.v1.bak.json`；损坏配置另存为 `config.broken-时间.json`；高于 v2 的配置只读。写入串行执行并原子替换。正文缓存位于 `cache/doc/`，最大 500 MiB，按最近使用情况淘汰。目录管理可清除派生缓存。

界面设置位于 Electron 的 `~/Library/Application Support/PageShelf/`，与源资料、资料库配置分开。

## 开发与验证

需要 Node.js 24 LTS（24.15 或更高的 24.x 版本）或 Node.js 26+，在项目目录运行：

```sh
npm ci
npm run dev
npm run build
npm test
npm run check
npm run benchmark:search
npm run package:mac
```

`dev` 启动 Vite 与 Electron；生产应用直接使用自定义协议和独立库进程，不提供网页服务。`npm test` 运行 node:test、Vitest、构建和真实 Electron E2E；可用 `npm test -- --unit`、`--ui` 或 `--electron` 单独验证。测试用临时资料和受限废纸篓替身。`node scripts/package-smoke.mjs` 验证打包产物、六组布局、全部应用进程无监听端口及退出清理。

Inter、Space Grotesk 和第三方库均本地打包，许可证随应用附带。固定 vendor 版本与 SHA-256 见 [VENDOR.md](../src-ui/vendor/VENDOR.md)。开发结构和验证命令见 [开发指南](DEVELOPMENT.md)。

## 从旧版本迁移

已有资料库配置和源目录可直接继续使用。桌面版不需要登录时启动的旧后台服务。其他机器若仍安装旧服务，可在访达“前往文件夹”打开 `~/Library/LaunchAgents/`，移除 `com.local.html-conversation-library.plist` 后注销并重新登录；资料库配置与文章无需删除。

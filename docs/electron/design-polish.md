# PageShelf 界面与动效优化

日期：2026-10-22。按用户指定的 `emil-design-eng` 技能完成界面调整，交付应用已更新为 `release/PageShelf-darwin-arm64/PageShelf.app`。

## 界面变化

| Before | After | Why |
|---|---|---|
| 来源目录出现两层选中背景 | 单层选中背景与左侧标记，系列有连续层级线 | 更容易分辨当前来源和系列关系 |
| 字符图标、搜索和筛选控件样式不一致 | 统一 16px 线性图标、32px 控件及分段主题选择器 | 保持对齐和操作节奏；筛选仍使用原生 select |
| 标题、来源、格式、日期挤在同一层 | 强调标题，格式使用小标签，日期右对齐，来源可截断 | 扫描列表时优先看到内容，保留必要信息 |
| 正文标题与元数据缺少分隔 | 调整标题行高、留白与分隔线，弱化元数据 | 正文更容易连续阅读 |
| 菜单靠近窗口边缘时尺寸不稳定 | 按内容计算宽度，逐行布局，留出边缘空间，必要时向上展开 | 防止菜单展开后溢出或出现大片空白 |
| 对话框中的长路径出现横向滚动条 | 自动换行，统一关闭图标与操作区边界 | 小窗口和长文件名仍能完整阅读 |
| 提示计时受父组件重新渲染影响 | 每条提示保留独立剩余时间，悬停、聚焦、隐藏和失焦时暂停 | 给用户足够时间阅读和操作；错误提示保留至主动关闭 |

主要视觉样式在 [polish.css](../../src-ui/src/styles/polish.css)；共享图标和原生筛选包装位于 `src-ui/src/components/`。`item-list.tsx`、`sidebar.tsx`、`reader.tsx` 与 `App.tsx` 接入相应控件。

## 动效取舍

| 操作 | 实际行为 |
|---|---|
| 键盘快捷键、方向键、列表导航、主题与视图切换 | 即时响应；键盘输入会停止现有过渡 |
| 鼠标打开菜单 | 160ms 透明度与轻微位移/缩放，从触发位置展开 |
| 鼠标打开对话框 | 200ms 透明度过渡；不移动对话框，保持内部固定菜单的坐标正确 |
| 鼠标触发提示 | 160ms 透明度与 8px 位移 |
| 普通按钮按下 | 0.97 缩放反馈；导航、列表、主题和视图选项保持稳定 |
| 系统“减少动态效果” | 取消位移、缩放和滚动动效；鼠标浮层只保留最多 100ms 淡入 |
| 关闭浮层 | 立即关闭并按原规则恢复焦点 |

[input-modality.ts](../../src-ui/src/input-modality.ts) 按实际按键与按下鼠标事件识别操作方式，移动鼠标不会把键盘操作重新切成动画模式。使用现有时长、缓动和主题 token，以及 CSS `@starting-style`；没有新增动画依赖。

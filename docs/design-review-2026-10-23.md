# PageShelf 设计审核

审核日期：2026-10-23。依据 `emil-design-eng`，检查实际 Electron 应用与界面源码，使用仓库示例资料和独立测试配置。

## 结论

现有的三栏布局、低饱和蓝色、统一间距和阅读排版适合本地资料库。本次主要提高小字的可读性，补充目录展开、扫描进度和偶发弹窗的状态反馈。

## 设计元素

| 元素 | 审核结果 |
| --- | --- |
| 品牌与图标 | 标志有亮暗版本，字体随应用打包；图标尺寸和线条风格一致，保留。 |
| 配色与层级 | 正文和标题层级清楚；路径、日期、筛选说明及警告文字偏淡，已调整。 |
| 字体与阅读 | 界面、标题、正文分别使用相应字体；正文行高、段落间距、行宽和四档字号适合长文，保留。 |
| 布局与密度 | 来源、文章列表、正文职责明确；三栏可调整，窄窗口会折叠侧栏，保留。 |
| 边框、圆角与阴影 | 面板分隔较轻，选中状态同时使用背景与边线；圆角和浮层阴影统一，保留。 |
| 按钮与输入 | 已有按压、焦点、禁用状态和搜索焦点提示；新增危险按钮的鼠标悬停反馈。 |
| 菜单与弹窗 | 菜单已根据触发位置确定缩放原点，并能避开窗口边缘；信息和确认弹窗补充轻微缩放。 |
| 空状态与加载 | 空状态提供下一步操作；持续加载超过 200ms 才显示骨架，保留。 |
| 提示消息 | 已支持渐入、错误常驻以及窗口失焦、隐藏、鼠标停留、键盘聚焦时暂停计时，保留。 |
| 键盘与动态偏好 | 键盘操作即时响应；系统减少动态效果时去掉位移与缩放，保留并验证新增动效。 |

## 修改对照

| Before | After | Why |
| --- | --- | --- |
| 亮色辅助文字 `#7F8396`；暗色 `#6E717B` | 亮色 `#626875`；暗色 `#9498A3`，暗色代码注释复用辅助文字颜色 | 原先在基础表面的文字对比度最低约 3.51:1 / 3.64:1；调整后在基础表面和选中背景上均达到 4.5:1。对比度表示文字与背景的明暗差距，数值越高越容易辨认。 |
| 警告文字直接使用亮橙色 `--warning` | 警告说明、状态和徽标使用现有 `--status-waiting` | 区分用于提示状态的颜色与适合阅读的文字颜色。 |
| 危险按钮没有专属悬停反馈 | 仅在支持鼠标悬停的设备上显示颜色变化 | 明确提示按钮可操作，沿用现有按压反馈。 |
| 目录箭头瞬间旋转，系列内容直接出现 | 箭头旋转 160ms；系列内容在 160ms 内渐显并上移 4px | 解释目录展开后的内容归属；连续点击可以从当前状态反向过渡。 |
| 扫描进度通过改变 `width` 瞬间更新 | 固定轨道宽度，用 `scaleX()` 在 160ms 内更新；比例限制在 0–1 | 平滑表达真实进度，同时避免逐帧改变布局尺寸。 |
| 所有弹窗仅渐显 | 信息与确认弹窗在 200ms 内从 `.98` 缩放至正常大小，上移 8px 并渐显 | 增强偶发浮层的出现反馈，缩放原点保持居中。 |
| 对含嵌套菜单的弹窗直接增加缩放会改变菜单坐标参考 | 含 `aria-haspopup="menu"` 触发器的弹窗继续仅渐显 | 保持内部固定定位菜单的坐标稳定，避免入场时菜单偏移。 |

## 动效边界

新增位移、旋转和进度过渡只在指针操作、且系统未要求减少动态效果时启用，使用现有 `cubic-bezier(.23, 1, .32, 1)` 曲线。新增运动只改变 `transform` 和 `opacity`；按钮颜色反馈沿用现有短过渡。

搜索输入、列表选中、文章切换、主题切换和快捷键不增加等待时间。菜单与提示消息沿用现有入场动效；本次没有新增动画依赖。

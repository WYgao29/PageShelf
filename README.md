# 我的对话库

一个本机运行的 HTML/Markdown 对话统一入口。它不会搬动或改写源文件，只会扫描你指定的目录，在浏览器中把散落的对话整理成可搜索的记录。

## 启动

需要 Node.js 20 或更高版本。

执行 npm start，然后在电脑上打开 http://localhost:4321。要让同一 Wi-Fi 下的手机访问，在手机浏览器输入这台 Mac 的局域网 IP，例如 http://192.168.1.20:4321。

服务默认监听 0.0.0.0:4321。可以通过 PORT 和 HOST 环境变量修改，例如 PORT=5000 npm start。

## 添加内容目录

打开页面右下角或侧栏的“设置”，输入保存对话的文件夹路径。系统会递归扫描以下扩展名：

- HTML：.html、.htm
- Markdown：.md

同一扫描目录中相同相对路径的 HTML 和 Markdown 会合并成一条记录，例如：

    对话/项目规划.html
    对话/项目规划.md

源文件继续留在原来的位置。配置保存在用户目录下的 .html-library/config.json，索引在服务启动时从源文件重新建立。

## 常用操作

- 搜索框同时搜索标题、文件名、目录名和正文。
- “重新扫描”会立即读取所有已配置目录中的最新内容。
- 打开记录后可以切换 HTML 阅读和 Markdown 视图，也可以新窗口打开或下载源文件。
- 移除目录只会停止扫描，不会删除目录或其中的文件。

## 开发与验证

    npm test
    node --check src/server.js
    node --check public/app.js
    git diff --check

API 只读取显式配置的目录；源文件路由会再次验证记录对应的目录边界，避免通过路径参数读取白名单之外的文件。

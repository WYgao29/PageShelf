# 我的对话库

在本机浏览 HTML、MHTML 和 Markdown 资料：左侧选择来源目录与系列，中间搜索和筛选，右侧直接阅读。扫描和移除目录不会改写源文章；只有明确确认“移入废纸篓”才会移动该条目的关联文件。

## 启动与独立开发

需要 Node.js 20 或更高版本。运行时没有 npm 依赖，也不需要下载前端库。

```sh
npm start
```

打开 <http://127.0.0.1:4321>。默认只监听本机；`PORT`、`HOST` 和 `HTML_LIBRARY_DATA_DIR` 可修改端口、监听地址和数据目录。已有后台服务时，重复启动会显示“服务已在运行”并正常退出。

开发和验收使用独立端口、独立配置，避免操作当前后台实例：

```sh
PORT=4322 HOST=127.0.0.1 HTML_LIBRARY_DATA_DIR=/tmp/html-library-dev npm run dev
```

如需局域网访问，必须显式配置 `AUTH_TOKEN`：

```sh
AUTH_TOKEN='请换成足够长的随机字符串' HOST=0.0.0.0 npm start
```

首次打开 `http://这台Mac的局域网IP:4321/?token=你的令牌`，服务会保存 `HttpOnly; SameSite=Strict` Cookie 并跳转到无令牌的地址。后续 API、阅读页和源文件请求使用此 Cookie 或 Bearer 令牌。

## 来源目录

在侧栏点击“添加目录”或“管理”，选择文件夹或粘贴完整路径，可设置 1–40 字显示名。添加前会预检路径、重复来源、文件数与条目数，并说明重叠影响；不通过的预检不会保存配置。

支持 `.html`、`.htm`、`.mhtml`、`.mht`、`.md`。同一来源中相同相对路径、相同文件名主干的不同格式合并为一条资料。HTML 筛选也包含 MHTML。

父子目录重叠时，资料归属**最深的可用目录**，不会重复计数。停用、失效或移除子目录后，可用父目录会回收相应资料。移除来源只取消索引，源文件保留；同名来源可同时存在，使用路径区分。

目录 ID 与路径分离。改名、排序不触发文件读取，ID 保持不变；重新定位到移动后的目录时，只要内部相对路径不变，条目链接仍然可用。将资料交给另一个来源时，条目 ID 会随归属来源变化；移除子来源后恢复父来源的原 ID。

目录菜单提供增量/全量重扫、重新定位、停用/启用、系列识别开关、访达显示和移除。拖动排序，也可聚焦拖动按钮后按 `Alt+↑/↓`。扫描全局最多同时处理两个来源，每个来源串行；旧结果在新索引完成前仍可浏览。读取失败会显示目录状态与问题列表。

## 阅读、搜索与界面

点击文章在右侧阅读；原网页使用带 `sandbox` 的 iframe，纯 Markdown 可查看源文本，同时包含网页与 Markdown 的资料可切换三个视图。正文抽取不足 200 字或找不到正文时显示原因并回退原网页；短 Markdown 仍按笔记阅读。

搜索覆盖标题、系列、标签、相对路径和正文。空格表示同时匹配，双引号表示短语，`-词` 排除匹配内容。可切换当前目录/全部目录范围、格式、系列/单篇和排序。列表显示原文高亮和命中数，分组默认显示六篇，可展开更多；长结果按每批 100 条继续加载。

目录/系列、搜索、筛选、排序、正在阅读的条目与视图写入 URL，可刷新或后退恢复。右侧目录跟随正文滚动；系列上一篇/下一篇使用完整系列顺序，不受搜索结果数量影响。

主题支持亮色、暗色和跟随系统；`Aa` 可选 15/17/19/21 px。两条栏间分隔线支持拖动和方向键调整，双击恢复 252/384 px。主题、字号和栏宽存在 `localStorage`；不会保存已读、收藏或用户阅读进度。

| 快捷键 | 操作 |
|---|---|
| `⌘K` / `/` | 聚焦搜索 |
| `Esc` | 关闭菜单/弹窗，或清空搜索 |
| `j` / `k` / `Enter` | 选择下一/上一条，打开选中条目 |
| `[` / `]` | 系列上一篇/下一篇 |
| `v` | 切换阅读视图 |
| `n` / `Shift+N` | 下一处/上一处正文命中 |
| `g a` / `g 1–9` | 全部目录/指定目录，前缀间隔不超过一秒 |
| `Shift+R` / `Shift+M` | 全部重扫/目录管理 |
| `t` / `⌘\` / `?` | 切换主题/折叠侧栏/快捷键帮助 |

输入框、可编辑区和弹窗内不会触发单字母快捷键。非 macOS 键盘可用 `Ctrl+K` 和 `Ctrl+\`。

## 废纸篓与恢复

在阅读区“文章操作”中选择“移入废纸篓…”，确认框会列出全部关联源文件。macOS 优先使用系统 `trash`，必要时使用访达移动；不会使用源文件 `unlink`。部分成功时保留幸存格式并列出失败文件，可重试剩余文件；全部失败时展示错误。

恢复时打开访达废纸篓，选中文件并点击“放回原处”，随后重扫相应来源。目录管理也提供“打开废纸篓”。如果系统限制访达自动化或来源目录访问，先检查系统实际给出的权限提示，也可在访达完成移动后重扫；应用会保留失败信息。

## 配置、缓存与内嵌库

默认配置为 `~/.html-library/config.json`。v1 启动时只在内存中转换，首次配置修改前原字节备份为 `config.v1.bak.json`；保留旧目录 ID、已核对的条目 ID 算法和未知字段。新来源按 NFC 相对路径计算条目 ID。

损坏配置会另存为 `config.broken-时间.json`，界面显示恢复提示。高于 v2 的配置保持只读，兼容目录结构仍可浏览、重扫、选择文件夹和清理缓存；结构不兼容时显示说明和空库，原配置字节不变。配置写入使用串行队列与临时文件原子替换。

索引仅在内存中，启动时重建。解码正文缓存在数据目录的 `cache/doc/`，根据文件路径、格式、mtime、size 和 inode/dev 区分，最大 500 MiB，按访问时间淘汰。目录管理“清除缓存”删除这些派生内容，下次阅读重新生成。

前端本地内嵌库：marked 18.0.14（MIT）、DOMPurify 3.4.16（Apache-2.0）、Readability 0.6.0（Apache-2.0）。原发布文件、许可证与 SHA-256 位于 [VENDOR.md](public/vendor/VENDOR.md)。主界面 CSP 禁止自动外连；正文使用清洗节点和统一 CSS，外部图片显示占位，Markdown 本地图片再次验证来源边界与实际图片类型。

## macOS 后台服务与回退

```sh
npm run service:install
npm run service:status
npm run service:stop
npm run service:uninstall
```

安装写入 `~/Library/LaunchAgents/com.local.html-conversation-library.plist`，绑定执行命令时的项目路径与 Node 路径，登录时启动，异常退出才自动拉起。日志在 `~/Library/Logs/html-conversation-library/`。移动项目、更新服务代码或重启策略后，需要从准备投入使用的项目目录重新执行 `service:install`。

发布前保存已有 plist、配置与日志状态，验收完成后再切换服务。本轮阶段 tag 为 `ui-v2-p0` 至 `ui-v2-p4`，均保留可恢复废纸篓实现。若要回到 v1 配置代码，先停止服务、另存当前 v2 配置与新增来源清单，再恢复已保存的 v1 备份；旧代码不得直接写回 v2 配置。完整待发布步骤见 [发布清单](docs/verification/release-checklist.md)。

## 开发与验证

```sh
npm test
npm run check
npm run test:browser
npm run benchmark:search
git diff --check
```

浏览器测试使用本机 Chrome 与独立临时配置、资料和用户配置目录。缺少 Chrome 返回退出码 2，代表未完成，不能算通过。可用 `CHROME_PATH` 指定可执行文件。

```sh
npm run test:browser -- --force-failure
npm run test:browser -- --real --screenshots
npm run test:browser -- --serve
```

`--force-failure` 验证失败会返回退出码 1。`--real --screenshots` 读取真实配置的临时副本和真实源资料，核对标题/抽取结果并生成布局截图；重名、失效与扫描状态使用专用空目录，仅修改临时配置，源文章保持只读。扫描截图使用受控进度状态，真实队列执行另有行为测试。

`--serve` 输出随机本机测试 URL，可在 Safari 或 Edge 手工打开；完整结果按浏览器与日期保存为 `docs/verification/browser-*.json`。终端 `Ctrl+C` 停止服务并清理临时资料。此测试入口使用合成资料和专用废纸篓替身，不会出现在生产服务中。

验收结果、测量方法和未完成的人工检查见 [v2 验证记录](docs/verification/html-library-v2.md)。可选 B5 子文件夹树未纳入本轮。
